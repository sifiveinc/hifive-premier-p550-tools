# hifive-premier-p550-tools
Tools for SiFive HiFive Premier P550 Boards

## Description

This repository contains various tools and firmware for SiFive HiFive Premier P550 Boards.
Below are the various sub-directories and description of what it contains:

- `ddr-fw`: Contains DDR firmware binary used to initialise on-board SDRAM DDR device.
- `es-mac-id-update-tool`: Contains Windows, Linux and Mac OS based utility to update the MAC addresses on development board.
- `esburn`: Contains Windows and Linux OS based programming tool to program bootchain, kernel and rootfs images.
- `jtag`: Contains tool for debugging the device using JTAG.
- `mcu-firmware`: Contains MCU firmware that needs to be flashed into MCU using JTAG interface.
- `second_boot_fw`: Contains Second Boot firmware binary used for genetating bootchain image.
